# 05 ゲームデザイン確定版（v3）2026-10-13

仮タイトル：**らくがき勇者**（候補：白紙の勇者／ノートのすみの勇者。Xアカウントを作るときに決める）

## 一言
真っ白なノートに描かれた落書きの勇者が、世界の色を消しに来る「ケシカス」の群れから生き延びる。**世界に色を足せるのは、プレイヤーの要望だけ。**

## コアループ（1回 最大5分）
1. 指を置いた場所が中心になるスティックで移動（左右どちらの手でも可）。PCは WASD／矢印キー
2. 武器は自動で攻撃する。ケシカスを倒すと「色のしずく」（経験値）が落ちる
3. しずくを拾ってレベルアップ → 3択から1つ選ぶ（新しい武器／武器の強化／能力アップ）。1回目のレベルアップは開始10秒以内に来るように調整する
4. 5:00でボス「おおけしごむ」が出る。倒したらクリア。やられたら結果画面へ
5. 敵が落とした「インク」を持ち帰り、「ふでばこ」で永続的に強化する → 次の挑戦へ

## モード
- **自由帳**：何回でも遊べる通常モード
- **今日のページ**：日本時間の日付でシード（乱数の種）を固定し、「きょうの異変」が1つ付く。1日最初の1回が本番で、結果をシェアできる。2回目以降は練習扱い
- インク（永続強化の通貨）はどちらのモードでも溜まる

## 中身（テスト版＝Day 0）
### 武器（最大4枠、各レベル1〜5）
| 名前 | 動き | 色 |
|---|---|---|
| えんぴつ | 一番近い敵へ芯を飛ばす（初期装備） | 黒 |
| じょうぎ | 進行方向に扇状の一振り。ノックバックが強い | 黒 |
| コンパス | 周りを回る針 | 黒 |
| かみひこうき | ゆっくり敵を追いかける。貫通する | 黒 |
| あおいクレヨン | 歩いた跡に青い線を残す。触れた敵を遅くする | **青（Day 0の色）** |

### 能力アップ（最大4枠、各レベル1〜5）
くつ（移動速度）／ばんそうこう（最大HP）／じしゃく（拾える範囲）／とがった芯（威力）／はやがき（攻撃の速さ）／よはく（経験値の量）

### 敵
| 名前 | 動き | 出てくる時間 |
|---|---|---|
| ケシカス | ゆっくり追ってくる | 0:00〜 |
| はしりケシカス | 速いが脆い | 0:45〜 |
| かたまりケシカス | 硬い。倒すと小さなケシカス2つに分かれる | 1:30〜 |
| とびケシカス | 距離をとって赤い線（弾）を撃つ | 2:30〜 |
| おおけしごむ（ボス） | 突進して、こすった跡を一時的に危険地帯にする | 5:00 |

### ふでばこ（永続強化）
たいりょく／いりょく／はやさ／ひろう範囲（各5段階）、ふっかつ（1段階）。値段は段階ごとに上がる。

### きょうの異変（Day 0は3つを日替わりで回す）
- **ケシカスがでかい**：敵が大きく・遅く・硬い
- **はやおき**：すべてが1.3倍速
- **まっくら**：主人公のまわりしか見えない

## 謎と年表
- **ノート（年表）**：1日1ページ。その日に追加されたものを、色付きの絵と「誰の要望か」（XのID）で記録する。Day 0は「らくがきの勇者が描かれた（くろ）」
- **白紙の扉**：ノートの最後のページにある開かない扉。ゲージは「Xに届いた声（リプ）の数」で溜まる。節目は 10／30／100／300／1000。数はくろが数えた実数だけを使う（盛らない）
- **かけら**：条件を満たすと読める世界の断片。Day 0は1つ（初めてクリアすると読める）
- 真相の設定は非公開の設定資料で管理する（ブレないように）

## 要望の受け止め方（毎日の追加の差し込み口）
| 種類 | 例 | 入れ先 |
|---|---|---|
| もの | 「ハサミの武器がほしい」 | 武器・能力のデータ定義に追加 |
| いきもの | 「回転する敵」 | 敵のデータ定義に追加 |
| できごと | 「重力を逆にして」 | **きょうの異変**に追加（1日だけ。好評なら常設に昇格） |
| ばしょ | 「海のステージ」 | ステージ（テスト版の後に実装） |
| せってい | 「勇者に名前を」 | 年表・かけら（世界観）に反映 |

- 新しく追加したものには、その要望の色がつく。色ごとに性質を持たせる（赤＝威力、青＝遅くする、黄＝範囲…）。色の組み合わせによる新しい効果は、テスト版の後に実装する（仕組みの枠だけ用意しておく）
- クレジットは、くろが中身を確認した要望だけ。IDに不適切な語が含まれる場合は「名もなき絵描き」と表記する

## シェア
- 結果を「絵日記1ページ」の画像として端末内で生成し、スマホの共有シートで共有する
- 共有シートが使えない環境では、文字列＋Xの投稿画面を開くリンクにする
- 文字列の例：`らくがき勇者 Day 3「今日のページ」 4:12 生存 🟦🟦🟦⬜⬜ #らくがき勇者`

## 見た目と音
- **地**：方眼ノート（紙 `#FDFEFF`、方眼の線 `#D6E4F3`、24pxごと）。クリーム色の地は使わない
- **線**：太めのマーカー線（主線 `#2E3138`）。1秒に8回だけ線をわずかに揺らす「ラインボイル」で、手描き感を出す
- **読みやすさの基準**：主人公＝太い黒線＋その日の色の縁取り／敵＝灰色の塗り（`#8A8F98`）＋濃い縁（`#4B4F57`）／敵の攻撃＝赤い線（`#E2463A`）／しずく＝その色で光る点（Day 0は青 `#2F6FE4`）
- **文字**：手書き風の日本語フォント（SIL OFL）。使う文字だけを抜き出して同梱する
- **手触り**：重要度3段階（小：音＋粒／中：＋一瞬の停止＋揺れ／大：＋光＋大きい揺れ）。倒したときはケシカスがくしゃっと潰れる。揺れ・点滅は設定でオフにできる
- **音**：WebAudioで合成（えんぴつのカリッ、紙の当たり音、くしゃっ、拾う音（連続で拾うと音程が上がる）、レベルアップ、被弾、ボス警告、クリア）

## 画面
タイトル → モード選択（自由帳／今日のページ）→ ゲーム → 結果（シェア）。ほかに「ふでばこ」（永続強化）、「ノート」（年表・扉・かけら）、「せってい」（音・揺れ・点滅）

## 技術
- Phaser 4（リポジトリ内に同梱）、ES Modules、ビルド工程なし、静的サイト（GitHub Pages）
- ゲームのロジックは固定の時間刻み（1/60秒）で進め、シードが同じなら同じ展開になるようにする。描画はPhaserに任せる
- セーブ：localStorage、`version` 付き、読み込み時に移行と検証、壊れていたらバックアップに戻す
- テスト用の差し込み口：`?test=1` で自動の時間進行を止め、`window.advanceTime(ms)`・`window.render_game_to_text()`・`window.__test`（モード開始・入力・選択）を使えるようにする
- タブを離れたら自動で一時停止
- 敵の数の上限は300体。オブジェクトは使い回す（プール）

## 品質の関門（毎回の更新で必ず通す）
1. セキュリティの自動チェック（`03_security.md` の禁止パターン、CSPの存在）
2. Playwright でのスモークテスト：起動 → 自由帳 → 移動 → レベルアップ選択 → やられる → 結果 → タイトル。今日のページも同様に確認。コンソールにエラーがないこと
3. セーブ：保存 → 再読み込み → 一致。前のバージョンのセーブも読み込めること
4. バランス監視：3種類のボット（動かない／ランダム／逃げる）に固定シードで各50回遊ばせる。初回の計測で基準を決め、以後は生存時間の中央値が±20%を外れたら不合格
5. スクショの目視（スマホ縦・PC横）

## テスト版で「やらないこと」
仲間／複数キャラ／複数ステージ／色の組み合わせ効果（枠だけ用意する）／オンライン要素／動画の自動撮影／アクセス解析／BGM（効果音のみ）／多言語対応

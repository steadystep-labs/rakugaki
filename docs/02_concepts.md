# 02 ゲーム案（2026-10-13）

## どの案でも守る8つの柱（調査 `01_research.md` から）

1. **一言ルール・5秒で開始**：ログインも説明画面もなし。触ればわかる
2. **毎日来る理由**：「今日のアップデート（Day N）」と、全員同じ「今日のお題」（同じシード）。結果はネタバレなしの形で、Xの投稿画面を開くリンクから共有する（APIを使わないので0円・個人情報なし）
3. **成長の手応え**：負けても何か少し残る。1回もムダにしない
4. **くすぶる謎**：目的は説明しない。世界の断片を毎日1つ足す。隠し要素も日替わりで1つ
5. **みんなで作ってる感**：採用した要望はゲーム内の年表に「Day 12：〇〇が来た（@要望者）」と残す。クレジットは外してと言われたら外す
6. **手触り**：反応は重要度で3段階に分ける（小：音＋小さな粒、中：＋一瞬の停止＋揺れ、大：＋光＋大きな揺れ）。動きはすべてイージング。揺れ・点滅は設定でオフにできる
7. **見た目を固定**：このゲーム専用の配色と形のルールを最初に決めて、毎日の追加もそれに従う（AIっぽい既定デザインは使わない）
8. **壊れない**：セーブにはバージョン番号を入れて、古いセーブも移行できるようにする。毎日の追加は決まった差し込み口（データ定義）から行い、自動テストを通ったものだけ出す

## 案A「はじまりの部屋」（仮）― 謎×放置×拠点づくり

- **一言**：真っ暗な画面の小さな火を守りながら、少しずつ世界を広げていく
- **流れ**：タップで薪を集めて火を育てる → 人が来る → 道具や建物が増える → 外の世界へ出られる。放っておいても少しずつ進む
- **成長**：拠点と世界が育つ
- **謎**：なぜ世界がこうなったのか。日記・石碑などの断片が毎日1つ見つかる
- **要望の吸収**：◎ 建物・住人・道具・場所・出来事、何でも「世界の要素」にできる
- **Xでの見栄え**：△〜○ 文字中心なので映えにくい。考察は強い
- **弱点**：派手さがない。おもしろくなるまで時間がかかる

## 案B「ひとりの勇者」（仮）― 片手で遊ぶ自動攻撃ローグライト（縦画面）

- **一言**：指でよけるだけ、攻撃は自動。1回3分。倒れても少し強くなって、また挑む
- **流れ**：敵の群れをよけながら生き残る → 経験値で武器・技を選ぶ（毎回3択）→ 倒れたらお金を持ち帰って永続強化 → また挑む
- **成長**：主人公が永続的に強くなる。武器・仲間・技が増える
- **謎**：ステージの奥に「まだ誰も開けられない扉」がある。日替わりで鍵や伏線を1つずつ足す
- **毎日**：全員同じ「今日のダンジョン」（同じシード）で、生存時間をシェア
- **要望の吸収**：○ 武器・敵・仲間・ステージは足しやすい。仕組みそのものを変える要望は数日がかりになる
- **Xでの見栄え**：◎ 動きがあるので、スクショも動画も映える
- **弱点**：毎日の追加でバランスが崩れやすい（→ ボットに何百回も遊ばせる自動テストで見張る）。実装量は3案で一番多い

## 案C「ふしぎな生き物」（仮）― 育成×図鑑×隠し進化

- **一言**：謎のタマゴから生まれた生き物を育てる。何を与えたかで進化先が変わる
- **流れ**：エサ・遊び・おでかけ → 進化 → 図鑑が埋まる。1日1回の「おでかけ」でアイテムが手に入る
- **成長**：生き物の進化と、図鑑のコレクション
- **謎**：誰も条件を知らない隠し進化がある。ヒントは日替わりで1つだけ → 考察が起きる
- **毎日**：全員共通の「今日の天気」で、出やすい進化が変わる
- **要望の吸収**：◎ エサ・おもちゃ・進化先・場所
- **Xでの見栄え**：○ かわいさと図鑑の自慢
- **弱点**：腕前の要素が薄い。絵の質がそのまま評価になる（AIがいちばん苦手な部分）

## くろのおすすめ：案B ＋ 案Aの「謎」

- オーナーの言う「メインプレイヤーが成長していく」にいちばん素直に合う
- 片手・縦画面・1回3分は、Xから来たスマホの人にちょうどいい
- 武器や敵の要望は、アクションゲームでいちばん出やすい種類の要望。採用しやすく、採用されたことが目に見えやすい
- 「開かない扉」という謎を1本通すと、カオスに育っても話がつながる
- 弱点のバランス崩壊は、自動のバランステストで抑えられる。見た目は図形とパーティクルで勝負できるので、絵の質に頼らずに済む

**ただし向き不向きがある**：作る量がいちばん多いので、テスト版までの時間は案Aや案Cより長くなる。手早く出して反応を見たいなら案Aが軽い。

## 自分で見つけて直した問題
1. 敵が画面外にばかりいて、序盤がスカスカ → 出現位置を画面の縁のすぐ外に変更
2. ボスが取り巻きに守られて倒せない → 射程内ならボスを優先して狙う＋突進後のふらつき
3. 当たり続けるとボスが青い四角になる → 光る演出は0.25秒に1回まで
4. お知らせが重なって画面からはみ出す → 1つずつ表示し、幅に合わせて縮める
5. 大きい敵の絵が端で切れる → 描画領域を広げた
6. まっくらの異変で上部の表示が読めない → 表示の下敷きを追加
7. 初めての人に操作説明がない → 初回の2回だけ説明を出す
8. 「かたまりケシカス」が強すぎて死因の大半 → 体力と攻撃を下げ、たまに回復アイテムが落ちるように
9. 構文エラー1件（改行の書き方） → 修正。スモークテストでも検出できる種類
